VINOD BIKE GARAGE - Android Studio Project

ఇది APK కాదు; APK build చేయడానికి Android Studio project source.

APK తయారు చేయడానికి:
1. కంప్యూటర్‌లో Android Studio install చేయండి.
2. ఈ ZIP extract చేయండి.
3. Android Studio > Open ద్వారా VinodBikeGarage folder ఎంచుకోండి.
4. Gradle sync పూర్తయ్యాక Build > Build Bundle(s) / APK(s) > Build APK(s) నొక్కండి.
5. APK సాధారణంగా app/build/outputs/apk/debug/app-debug.apk లో వస్తుంది.

గమనిక:
- App data ఈ app యొక్క WebView local storage లో ఉంటుంది.
- ప్రస్తుత Backup/Restore విధానం JSON ఫైల్ download/upload ఆధారితం.
- Google Drive automatic sync ఇంకా అమలు కాలేదు.
